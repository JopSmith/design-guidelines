# Feedback Loop

## 1. Intent (Why this exists)

Collects user feedback on system outputs. Improves system quality over
time.

## 2. Context of Use

-   Use when:
    -   Outputs can be evaluated
-   Avoid when:
    -   Feedback is not actionable

## 3. Core Behaviour (How it works)

-   Trigger:
    -   System displays output
-   System Response:
    -   Show feedback options
-   Ongoing Behaviour:
    -   Record user input
-   Exit Condition:
    -   Feedback submitted

## 4. Rules & Constraints

-   MUST:
    -   Capture feedback accurately
-   SHOULD:
    -   Keep interaction simple
-   MUST NOT:
    -   Force feedback submission

## 5. Variants

-   Variant A: Binary Feedback
-   Variant B: Detailed Feedback

## 6. Examples (Abstract, not visual)

-   System shows response
-   User clicks thumbs up

## 7. Rationale (Why it works)

-   Enables improvement
-   Engages users

## 8. Trade-offs

-   Pros:
    -   Valuable data
-   Cons:
    -   Low participation
