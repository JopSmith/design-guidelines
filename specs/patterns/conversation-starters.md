# Conversation Starters

## 1. Intent (Why this exists)

Provides predefined prompts to initiate interaction. Reduces effort to
start a conversation.

## 2. Context of Use

-   Use when:
    -   Users may not know what to ask
-   Avoid when:
    -   Users have clear intent

## 3. Core Behaviour (How it works)

-   Trigger:
    -   New session starts
-   System Response:
    -   Display starter prompts
-   Ongoing Behaviour:
    -   Update based on context
-   Exit Condition:
    -   User selects or types input

## 4. Rules & Constraints

-   MUST:
    -   Provide relevant examples
-   SHOULD:
    -   Keep prompts concise
-   MUST NOT:
    -   Overwhelm user with options

## 5. Variants

-   Variant A: Static Starters
-   Variant B: Personalized Starters

## 6. Examples (Abstract, not visual)

-   System shows prompts
-   User selects one
-   System starts conversation

## 7. Rationale (Why it works)

-   Reduces friction
-   Encourages engagement

## 8. Trade-offs

-   Pros:
    -   Easy onboarding
-   Cons:
    -   May bias interaction
