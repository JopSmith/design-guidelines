# Rich Content Cards

## 1. Intent (Why this exists)

Displays structured content instead of plain text. Improves clarity for
complex or visual information.

## 2. Context of Use

-   Use when:
    -   Data is structured or visual
-   Avoid when:
    -   Content is simple text

## 3. Core Behaviour (How it works)

-   Trigger:
    -   System generates structured data
-   System Response:
    -   Render content as card
-   Ongoing Behaviour:
    -   Allow interaction within card
-   Exit Condition:
    -   User navigates away

## 4. Rules & Constraints

-   MUST:
    -   Present structured data clearly
-   SHOULD:
    -   Include actions when relevant
-   MUST NOT:
    -   Replace simple text unnecessarily

## 5. Variants

-   Variant A: Static Card
-   Variant B: Interactive Card

## 6. Examples (Abstract, not visual)

-   System returns product
-   System renders product card

## 7. Rationale (Why it works)

-   Improves readability
-   Supports actions

## 8. Trade-offs

-   Pros:
    -   Clear structure
-   Cons:
    -   More complex UI
