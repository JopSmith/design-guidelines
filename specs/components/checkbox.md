# Checkbox

## 1. Description

A Checkbox is a form control that allows users to select one or more options from a set. Each checkbox represents an independent choice, meaning multiple checkboxes in the same group can be selected at the same time.

## 2. Usage

### When to Use

Use Checkboxes when users need to make multiple, non-exclusive selections or toggle individual options on or off. They are well suited for settings, preferences, and lists where each choice stands alone. Checkboxes work best when the outcome of selecting or deselecting an option is clear and predictable.

### Do
- Use Checkboxes for options that can be selected independently
- Use clear, concise labels that describe the option
- Group related Checkboxes logically
- Reflect the current state clearly when checked or unchecked
- Use a Checkbox to toggle a setting on or off
- Support keyboard and assistive technology interaction

### Don't
- Use Checkboxes when only one option should be selected
- Use vague or ambiguous labels
- Scatter related options across the interface
- Hide state changes or rely on subtle cues
- Use a Checkbox for immediate actions or navigation
- Make Checkboxes inaccessible or hard to interact with
