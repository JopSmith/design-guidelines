# Chip

## 1. Description

A Chip is a compact element used to represent statuses, tags, or filters in a concise and visually distinct way. Chips typically display short labels and may include icons, Avatars, or a dismiss action, making them useful as visual indicators or enabling lightweight interactions.

## 2. Usage

### When to Use

Use Chips to communicate state, categorise content, or show applied filters without taking up excessive space. They work especially well in lists, search results, and filtering interfaces, where users need to quickly understand or adjust context. Chips are best suited for lightweight interactions and supplemental information rather than primary actions.

### Do
- Use Chips to display statuses, tags, counters, or filters inline
- Keep Chips short and concise, ideally one or two words
- Use contextual colours to communicate meaning consistently
- Use Chips inline with other content for lightweight emphasis
- Use **outline** Chips by default when no specific context is required
- Use **solid** Chips when clear contextual emphasis is needed, typically as standalone elements, e.g. in PageHeaders
- Use **soft** Chips when context is required, but the design calls for a lighter, less intrusive style, e.g. in tables, lists, or cards
- Use **filter** Chips only for displaying and toggling filters
- Use **extra small (XS)** Chips as the default size for statuses, tags, and inline indicators
- Use Chips consistently and for the correct use case

### Don't
- Overuse Chips across a page — this reduces their impact
- Use Chips for long descriptive labels or sentences
- Combine inaccessible colours (e.g., red Chip on green background)
- Use Chips as primary navigation or large action triggers
- Use outline Chips when context is required
- Use solid Chips in dense layouts like tables or lists — they're too visually heavy when repeated in close proximity
- Use soft Chips where strong emphasis or standalone context is needed
- Use filter Chips to display non-interactive statuses or labels
- Use medium or large Chip sizes — these are generally not used
- Mix Chip styles inconsistently across similar use cases
