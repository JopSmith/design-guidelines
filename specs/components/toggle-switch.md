# ToggleSwitch

## 1. Description

A ToggleSwitch component, also known simply as a Toggle, is a binary form control that allows users to switch between on and off states. It provides immediate visual feedback and typically takes effect as soon as it is changed, without requiring a separate save action. The control clearly indicates its current state through position and colour, making it easy to understand at a glance.

## 2. Usage

### When to Use

Use a ToggleSwitch for settings, preferences, or feature controls that require instant activation or deactivation. It is well suited to scenarios where changes apply immediately and do not require confirmation or additional input. Avoid using it for multi-option choices, complex configurations, or actions that should not take effect without review.

### Do
- Use ToggleSwitches for enabling or disabling features or settings
- Use ToggleSwitches for immediate state changes that take effect instantly
- Place labels to the right of the ToggleSwitch for clarity
- Keep labels concise, clear, and in sentence case
- Keep the ToggleSwitch and label aligned in the same column
- Ensure the current state is clearly visible through position and colour
- Provide accessible labels and keyboard support
- Use consistent spacing between ToggleSwitches in a list

### Don't
- Use ToggleSwitches for yes/no or single-choice questions in forms
- Use ToggleSwitches where confirmation is required — use Buttons instead
- Place labels above, below, or detached from the ToggleSwitch
- Use vague or overly long labels
- Separate the ToggleSwitch and label into different layout areas
- Rely only on colour without a clear positional indicator
- Make the ToggleSwitch difficult to use for keyboard or assistive technology users
- Place ToggleSwitches too close together, causing accidental changes
