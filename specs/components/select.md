# Select

## 1. Description

A Select component is a form input that opens a list of options in an overlay beneath the input field. When a user chooses an option, it is displayed within the field to confirm the selection. Select components support single selections and often include search or filtering to help users navigate longer lists efficiently. Unlike Dropdowns, which are used for navigation or triggering actions, Select components are designed specifically for use within forms.

## 2. Usage

### When to Use

Use a Select when users need to choose from 6 or more options, particularly when the list is long or benefits from filtering or search. It is well suited to structured form inputs where space needs to be conserved while still providing access to a comprehensive set of choices. Avoid using it for short lists where radio buttons would provide better visibility of all options at once.

### Do
- Use for 6 or more options in a form
- Use for multi-select when multiple answers are valid
- Group options logically with headings for clarity
- Match field width to the widest expected option
- Show selected items as Chips for clarity in multi-select

### Don't
- Use for 5 or fewer options — use RadioButtons instead
- Use for short binary choices — use RadioButtons or a Checkbox instead
- Present one long unstructured list of unrelated items
- Set a field width too narrow, truncating content
- Let multiple selections disappear into a collapsed field
