# SpeedDial

## 1. Description

A SpeedDial component, also known as a Floating Action Button (FAB), is a prominent circular action button that can represent a single primary action or expand to reveal a small set of related actions. It is typically fixed to a consistent position on the screen and is designed to highlight the most important task within a view. When expandable, it reveals secondary actions in a compact and accessible layout. It is mainly used on mobile where screen space is limited and quick access to key actions is essential.

## 2. Usage

### When to Use

Use a SpeedDial when there is a clear primary action or a small number of closely related secondary actions that need to remain easily accessible. It is particularly effective in content creation flows or task-driven interfaces where speed and visibility are important, especially on mobile interfaces. Avoid using it when there are too many actions, when actions are unrelated, or when a standard button within the page layout would provide clearer context.

### Do
- Use primarily on mobile where quick access to key actions is important
- Use for a single clear primary action or a small set of closely related actions
- Limit secondary actions to a small, well-related set
- Keep placement consistent such as bottom right
- Use clear icons with accessible labels
- Provide clear expand and collapse behaviour when revealing additional actions
- Ensure strong visual contrast and prominence
- Use for high-frequency or task-driven actions

### Don't
- Use as a default pattern on desktop without a clear need
- Include multiple competing primary actions
- Overload with too many or unrelated actions
- Position it where it obscures important content
- Rely on ambiguous icons without labels
- Leave the expanded state persistent without clear dismissal
- Make it blend into the background so it is hard to find
- Use for low-priority or rarely used actions
