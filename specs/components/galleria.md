# Galleria

## 1. Description

A Galleria is an image browsing and preview component that allows users to view visual content in an enlarged, focused overlay. Similar to a lightbox, it presents images in a prominent layer above the main interface and often supports navigation between multiple images, zoom controls, captions, and thumbnail previews. A Galleria helps users explore visual content in greater detail without leaving the current page.

## 2. Usage

### When to Use

Use a Galleria when users need to closely inspect images such as product photos, media assets, or visual documentation. It is particularly useful when images are central to the experience and require a distraction-free viewing mode, while still allowing users to return easily to their previous context.

### Do
- Use a Galleria when images require focused, enlarged viewing
- Provide clear navigation between images when multiple items are available
- Include a visible and accessible close action
- Support keyboard interaction such as arrow navigation and escape to close
- Display helpful context such as captions or image counts when relevant
- Maintain visual clarity with sufficient spacing and contrast
- Clearly indicate the currently active/selected item in the thumbnail row

### Don't
- Use a Galleria for small or purely decorative images
- Trap users on a single image without obvious navigation controls
- Rely solely on clicking outside the image to exit
- Design interactions that depend only on mouse input
- Overload the view with excessive text or distractions
- Clutter the overlay with unrelated controls or content
- Leave all thumbnails visually identical, which makes it hard to tell what's in focus
