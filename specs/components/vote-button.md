# VoteButton

## 1. Description

A VoteButton is an interactive control used to capture user preferences or opinions while displaying visible community feedback. It typically includes a vote count and provides immediate visual confirmation when selected, showing a thumbs-up icon once a vote has been made. This allows users to see both their own input and the broader community response in context.

## 2. Usage

### When to Use

Use a VoteButton when collecting lightweight feedback such as feature requests, content usefulness, or community sentiment where visible vote totals add value. It is particularly effective in collaborative or feedback-driven environments where users benefit from seeing how others have responded. Avoid using it for formal decision making, complex surveys, or situations that require detailed justification rather than simple preference input.

### Do
- Use VoteButtons to collect simple community preferences or opinions
- Display the current vote count clearly
- Provide immediate visual feedback such as a thumbs-up icon when selected
- Allow users to toggle or remove their vote where appropriate
- Use clear labels or tooltips to explain what the vote represents
- Use VoteButtons in collaborative or feedback-driven environments

### Don't
- Use VoteButtons for complex surveys or detailed feedback collection
- Hide the vote total so users lack context
- Give no confirmation that a vote has been recorded
- Lock users into accidental votes without recourse
- Assume users understand what they are voting for without context
- Use VoteButtons for critical decisions or formal approvals

## 3. Composition

The VoteButton consists of the following accessories:

| Accessory | Required | Description |
|---|---|---|
| Label | Optional | An optional short text label displayed alongside the vote count to clarify what the vote represents, such as "Upvote" — should be concise and action-oriented |
