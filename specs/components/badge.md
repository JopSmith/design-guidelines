# Badge

## 1. Description

A Badge is a compact UI element used to display dynamic information such as notification counts or status indicators. It is typically positioned on top of icons, navigation items, or other elements to draw user attention to changes or updates, without interrupting the user's flow.

## 2. Usage

### When to Use

Use Badges to surface concise, high-value information that benefits from immediate visibility, such as statuses, counts, or labels. They work best when paired with related elements like buttons, list items, or headers, and should remain short and unobtrusive so they enhance clarity without becoming a distraction.

### Do
- Use Badges to highlight counts or new notifications
- Position Badges on top of icons or nav items
- Keep Badge content short, e.g. numbers
- Ensure proper contrast between Badge and background
- Use Badges to indicate changes, not static info

### Don't
- Use Badges for labels, tags, or categories — use Chips instead
- Place Badges arbitrarily on unrelated UI components
- Use long text or complex content inside a Badge
- Use colours that reduce legibility or fail contrast check
- Use Badges for decorative purposes
