# MultiSelect

## 1. Description

A MultiSelect allows users to select multiple options from a dropdown list, with chosen items displayed as removable chips within the input field. It combines the behaviour of a dropdown menu with a token-based input, enabling users to review and manage their selections directly within the field. This approach keeps the interface compact while maintaining clear visibility of selected items.

## 2. Usage

### When to Use

Use a MultiSelect when users need to choose several related items from a predefined set, such as tags, filters, categories, or assigned roles. It is particularly effective when multiple selections are expected and users must be able to add or remove options easily without navigating away from their current context.

### Do
- Use a MultiSelect when users need to choose multiple items from a predefined list
- Display selected items clearly as removable chips within the field
- Provide search or filtering when the option list is long
- Keep option labels concise and easy to understand
- Allow users to remove selections easily and intuitively
- Maintain accessibility with keyboard support and clear focus states

### Don't
- Use a MultiSelect when only a single selection is allowed
- Hide selected values or make them difficult to review
- Force users to scroll through extensive unfiltered lists
- Use overly long labels that crowd the interface
- Make chip removal unclear or difficult to access
- Rely solely on mouse interaction to manage selections
