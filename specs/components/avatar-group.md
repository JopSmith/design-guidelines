# AvatarGroup

## 1. Description

An AvatarGroup displays multiple Avatars together to represent a collection of people or entities associated with the same context, such as a team, participants, or collaborators. It helps communicate group presence and scale at a glance while saving space by visually clustering identities.

## 2. Usage

### When to Use

Use AvatarGroups when you need to show shared ownership, participation, or collaboration without listing every individual in full. It works well in compact spaces like headers, cards, or lists, where conveying group involvement is more important than displaying detailed identity information. AvatarGroups help users quickly understand who's involved while keeping the interface visually balanced and uncluttered.

### Do
- Use AvatarGroups to show participants in a conversation, team members, or shared document collaborators
- Limit the number of visible Avatars (3–5) before collapsing into an overflow indicator, e.g. "+3"
- Order Avatars consistently, e.g. by most recent activity or role hierarchy
- Ensure Avatars are clearly distinguishable with sufficient spacing or overlap offset
- Provide meaningful alternative text for accessibility

### Don't
- Use AvatarGroups as standalone decorative imagery without purpose or association
- Display excessive Avatars that cause overflow or overlap readability issues
- Randomise or dynamically reorder Avatars between renders
- Overlap Avatars so heavily that identification is impossible
- Use Avatars as the only way to convey critical identity information
