# Splitter

## 1. Description

A Splitter component divides a container into two or more resizable panels, allowing users to adjust the relative size of each section dynamically. By dragging the divider between panels, users can control how much space is allocated to each area. This supports efficient use of horizontal or vertical space and enables flexible layouts within complex interfaces.

## 2. Usage

### When to Use

Use a Splitter in data-heavy or multi-pane environments where users need to compare, review, or edit content side by side. It is particularly suited to workspace-style applications such as dashboards, editors, or management tools where layout flexibility improves productivity. Avoid using it in simple layouts where resizing panels would add unnecessary complexity.

### Do
- Use a Splitter when 2 related content areas need to be viewed or compared simultaneously
- Allow users to resize panes smoothly with a visible handle
- Maintain clear visual separation between panels
- Provide sensible minimum and maximum widths for panels
- Use consistent visual styling across all Splitters

### Don't
- Use to divide completely unrelated content
- Hide or obscure the divider handle
- Merge panel borders so users cannot tell where one ends and the other begins
- Allow a panel to collapse entirely or overlap unless intentionally designed to do so
- Introduce inconsistent divider widths or handle colours across pages
