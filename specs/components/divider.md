# Divider

## 1. Description

A Divider is a visual element used to separate and organise content within a layout. It typically appears as a thin horizontal or vertical line that creates clear distinction between sections, groups, or related items. Dividers help structure information, improve readability, and guide the user's eye without adding additional content or complexity to the interface.

## 2. Usage

### When to Use

Use a Divider when you need to create visual separation between distinct sections of content, such as groups of form fields, navigation items, or blocks of information. It is particularly useful for improving clarity in dense layouts, but should be used sparingly to avoid visual clutter or unnecessary fragmentation of content.

### Do
- Use a Divider to separate clearly distinct sections of content
- Use Dividers to improve readability in dense layouts
- Align Dividers consistently with the layout grid and surrounding content
- Use Dividers to group related items within lists, forms, or panels
- Maintain appropriate visual hierarchy so Dividers remain subtle and supportive
- Use vertical Dividers only when separating content within the same horizontal space

### Don't
- Use a Divider when spacing alone would provide sufficient separation
- Overuse Dividers, as this can create visual clutter
- Place Dividers inconsistently or misaligned with content edges
- Use Dividers to separate items that are conceptually related and should remain visually connected
- Make Dividers overly prominent or decorative
- Use vertical Dividers where stacking or spacing would be clearer
