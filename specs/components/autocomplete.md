# AutoComplete

## 1. Description

An AutoComplete is an enhanced text input field that predicts and displays a list of suggested options as the user types. It helps users enter information more efficiently, reducing errors and cognitive load when selecting from known or repetitive data. AutoComplete improves form completion speed and accuracy by dynamically filtering options, particularly useful for long or complex datasets such as locations, names, or categories.

## 2. Usage

### When to Use

Use AutoComplete when users are expected to choose from a predefined or commonly reused set of values and speed or accuracy is important. It's especially effective in forms where typing full entries would be time-consuming or error-prone, such as selecting items from large lists.

AutoComplete should be used to guide users towards valid choices while still allowing quick input, making interactions feel faster and more confident without requiring extra effort.

### Do
- Use an AutoComplete for searchable lists or datasets where typing a few letters can narrow options
- Provide clear labels describing what users should search for
- Allow free text input if appropriate, to accommodate entries not found in the dataset
- Use it to reduce errors in repetitive data entry, e.g. addresses, names

### Don't
- Use an AutoComplete when only one or two possible options exist — when this is the case, use a Dropdown instead
- Use placeholder text as the only indicator of purpose
- Force selection from results unless required, as this can frustrate users if their input is valid but unlisted
- Overload AutoComplete lists with too many or irrelevant suggestions
