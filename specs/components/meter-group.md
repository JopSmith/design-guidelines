# MeterGroup

## 1. Description

A MeterGroup is a visual representation of multiple quantitative values shown as adjacent, proportionally filled segments within a single horizontal bar. Each segment represents a distinct category or metric and is colour-coded to support quick differentiation and pattern recognition. An accompanying legend provides clarity by linking each colour to its corresponding label, allowing users to interpret the data accurately at a glance.

## 2. Usage

### When to Use

Use a MeterGroup when you need to communicate relative proportions such as completion percentages, resource usage, or distribution breakdowns within a single total. It is particularly effective when comparison between categories is more meaningful than viewing standalone figures, and when a compact, easily scannable visual summary is required.

### Do
- Use MeterGroups to compare parts of a whole or to visualise proportional data, e.g. progress across categories
- Keep the number of segments limited (ideally 2–5) for readability
- Ensure each segment colour has sufficient contrast and clear association in the legend
- Display percentage or numeric values only when meaningful and space allows
- Align legends horizontally and maintain visual alignment with the bar

### Don't
- Use MeterGroups for unrelated metrics that don't share a common scale or denominator
- Overload the bar with too many segments, making differences indistinguishable
- Use arbitrary or duplicate colours that confuse meaning
- Force values to display within narrow segments where text would be truncated
- Separate the legend from its corresponding meter bar

## 3. Composition

The MeterGroup consists of the following accessories:

| Accessory | Required | Description |
|---|---|---|
| Icons | Optional | Allows icons to be used with labels to add extra visual identification |
| Labels | Optional | Allows labels to be shown, horizontally or vertically, with the related values |
