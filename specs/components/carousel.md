# Carousel

## 1. Description

A Carousel displays a collection of related content items within a single, horizontally scrollable container. It allows users to move through items one at a time or in small groups, helping surface multiple pieces of content without overwhelming the layout.

## 2. Usage

### When to Use

Use a Carousel when you need to showcase a limited set of related, visually rich items — such as images, cards, or featured content — within a constrained space. Carousels work best when users can easily understand what's being shown and control navigation at their own pace. They should highlight content that benefits from visual browsing rather than critical information that users must see immediately.

### Do
- Use Carousels for horizontally comparable content such as related items, steps, or featured cards
- Keep each card self-contained and independently meaningful
- Limit the number of visible navigation targets — show no more than 5–7 slides before collapsing behind indicators or alternative navigation
- Use clear visual affordances for previous/next navigation
- Use consistent sizing and spacing for all items in a carousel run
- Use Carousels for supplementary or exploratory content
- Ensure navigation controls are clear and easy to use
- Support touch, mouse, and keyboard interaction

### Don't
- Use a Carousel for critical information that must always remain visible without interaction
- Split a single piece of content across multiple slides so the user needs to scroll to understand it
- Overload or create very long carousels that require extensive manual clicking to reach content
- Use hidden or low-contrast navigation controls that only appear on hover for desktop
- Mix radically different item layouts and heights in one carousel
- Use Carousels for critical content users must not miss
- Rely on auto-rotation without giving users control
- Make Carousels inaccessible to keyboard or screen reader users
