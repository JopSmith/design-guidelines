# ColorPicker

## 1. Description

A ColorPicker is an input component that allows users to select a colour from a defined set or a continuous spectrum. It supports precise colour selection and preview, helping users apply colour choices confidently and consistently.

## 2. Usage

### When to Use

Use a ColorPicker when users need to choose or customise colours for elements such as themes, backgrounds, charts, or annotations. It works best in creative or configuration contexts where visual feedback is important. ColorPickers should make common choices easy while still allowing precision when needed.

### Do
- Use a ColorPicker when colour choice directly affects visual output
- Provide immediate visual feedback or preview of the selected colour
- Offer sensible defaults or a curated palette when appropriate
- Support precise selection with inputs like sliders or hex values
- Ensure colour choices meet accessibility requirements
- Use ColorPickers in settings or creation flows

### Don't
- Use a ColorPicker when colour is not a meaningful or necessary option
- Require users to apply or save before seeing the result
- Force users to choose from an overwhelming range of colours
- Limit users to imprecise or unclear controls
- Allow selections that reduce contrast or readability
- Use ColorPickers for quick binary or non-visual decisions
