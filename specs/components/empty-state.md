# EmptyState

## 1. Description

An EmptyState is an element that appears when there is no data or content to display within a given space. It typically includes a short message that explains why the area is empty and may be supported by an illustration or icon. An EmptyState helps set expectations, reduce confusion, and guide users towards the next appropriate action.

## 2. Usage

### When to Use

Use an EmptyState when a list, table, or section has no results, such as when a user has not yet created content or when a search returns no matches. It is particularly useful for encouraging action, providing guidance, or reassuring users that the system is functioning as expected, rather than leaving the space blank and unclear.

### Do
- Use an EmptyState to clearly explain why no content is displayed
- Provide a clear next step, such as a primary action to create or add content
- Keep messaging concise, supportive, and reassuring
- Tailor the message to the specific context, such as first use or no search results
- Use simple visuals or icons to support understanding where appropriate
- Maintain consistent tone and layout across the product

### Don't
- Leave empty areas without explanation
- Present an EmptyState without guidance on what to do next
- Use technical or system-focused language
- Use a generic message for all empty scenarios
- Rely solely on decoration without meaningful context
- Design EmptyStates that feel disconnected from the surrounding interface

## 3. Composition

The EmptyState consists of the following accessories:

| Accessory | Required | Description |
|---|---|---|
| Icon (Mandatory) | Mandatory | Displays an image to help understanding |
| Title (Mandatory) | Mandatory | Displays the name of the state |
| Subtitle | Optional | Appears below the title and used for secondary text |
| Action | Optional | Provides a contextual action or next step |
