# Avatar

## 1. Description

An Avatar is a small, circular graphical element used to visually represent a person, company, or other entity within an interface. It provides a quick, recognisable cue that helps users identify and distinguish identities at a glance across the UI.

## 2. Usage

### When to Use

Use Avatars to support quick recognition of people or entities across the interface, especially in areas where identity matters at a glance. Avatars can display a profile image, a user's initials, or a fallback icon when no image is available, ensuring consistency even with incomplete data.

They work well in user lists, comments, navigation headers, and account-related areas, where they help users scan content efficiently and understand context without relying on text alone. They can also add a human or brand presence to the interface, making interactions feel more personal and easier to follow.

### Do
- Use Avatars to provide access to a user's profile as this is a common pattern
- Use Avatars to clearly identify users or entities
- Provide a fallback (icon or label) if an image fails to load
- Keep all Avatar shapes perfectly circular
- Centre and scale content within the Avatar area
- Maintain consistent sizes and spacing across components

### Don't
- Hide access to a user's profile on a menu or sub navigation
- Use Avatars for generic decorative purposes
- Display a broken image without fallback
- Use inconsistent or non-circular shapes
- Allow content to appear misaligned or off-centre
- Mix Avatar sizes randomly or without design justification
