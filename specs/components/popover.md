# Popover

## 1. Description

A Popover is an overlay element that displays additional, non-critical information in response to a user action such as a click or tap. Unlike a Tooltip, which appears on hover, a Popover is intentionally triggered and dismissed through interaction. It can contain richer content such as a title, descriptive text, or lightweight structured content, while remaining anchored to the triggering element.

## 2. Usage

### When to Use

Use a Popover when you need to provide supplementary information or lightweight contextual content that enhances understanding but is not essential to completing the task. It is particularly suitable for explanations, previews, or secondary details that should be accessible on demand without interrupting the main workflow.

### Do
- Use for optional, non-critical supporting information
- Trigger on click or tap and provide an explicit close action
- Use concise text or simple structured content
- Position carefully to avoid covering important page content
- Include a visible close icon for dismissal
- Keep the Popover supplementary to the main task

### Don't
- Use to display essential or blocking information
- Trigger on hover or dismiss automatically on mouse out
- Overpopulate with complex or lengthy content
- Place the Popover so that critical information is hidden
- Force users to click outside only to dismiss
- Interrupt or replace core workflows with a Popover
