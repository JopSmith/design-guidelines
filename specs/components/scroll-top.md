# ScrollTop

## 1. Description

A ScrollTop component is a floating control that appears once a user has scrolled beyond a defined point on a page. It enables users to return instantly to the top of long content areas with a single interaction. The component typically fades into view as scrolling increases, providing a convenient and unobtrusive navigation aid.

## 2. Usage

### When to Use

Use a ScrollTop component on pages with substantial vertical content where users are likely to scroll extensively. It improves efficiency and reduces friction when navigating long articles, dashboards, or data-heavy views. Avoid using it on short pages where scrolling is minimal, as it adds unnecessary visual clutter without meaningful benefit.

### Do
- Use on content-heavy pages with significant scrolling
- Place consistently in the bottom right corner
- Trigger appearance only after sufficient scroll distance
- Provide smooth scrolling to the top
- Ensure proper aria label and focus state support

### Don't
- Use on pages with little or no scrolling required
- Position in places where it overlaps key page content
- Show permanently on pages with little content
- Snap instantly without transition if not accessible
- Use only an icon without an accessible label or description
