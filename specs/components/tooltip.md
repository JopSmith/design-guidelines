# Tooltip

## 1. Description

A Tooltip is a small pop-up message that appears when a user hovers over or focuses on an element. It provides supplementary information to clarify the purpose or meaning of icons, buttons, or other interface elements where intent may not be immediately obvious. Tooltips are brief, contextual, and non-intrusive, supporting understanding without permanently occupying space in the layout.

## 2. Usage

### When to Use

Use a Tooltip when additional explanation is helpful but cannot be displayed directly within the interface without creating clutter. They are particularly useful for icon-only controls or compact layouts where space is limited. Avoid using Tooltips to present critical information, lengthy instructions, or content that users must rely on to complete a task.

### Do
- Use Tooltips to provide short and supplementary explanations
- Trigger Tooltips via hover or focus
- Consider alternative patterns on mobile where hover is not available
- Keep Tooltip content concise and scannable
- Use Tooltips to clarify icon-only buttons when no label is possible
- Position Tooltips so they do not obscure the trigger element

### Don't
- Rely on Tooltips for essential information needed to complete tasks
- Require users to click to open a Tooltip on desktop — use a Popover instead
- Assume Tooltips will work the same on mobile without click-based interaction
- Repeat information already visible elsewhere
- Use Tooltips as a substitute for proper button labels
- Allow Tooltips to overlap or block the content being explained
