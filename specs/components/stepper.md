# Stepper

## 1. Description

A Stepper component displays progress through a defined sequence of steps within a process. It shows users where they are, which steps have been completed, and what remains. Steppers are commonly used in wizard-style flows where tasks must be completed in a specific order, helping to structure complex activities into clear and manageable stages.

## 2. Usage

### When to Use

Use a Stepper when a process requires multiple sequential stages and users need visibility of their progress. It is particularly effective for long forms, onboarding journeys, or setup tasks that benefit from being broken into smaller parts. Avoid using it when a task can be completed in a single step, when steps are not sequential, or when there are too many steps to fit clearly on screen.

### Do
- Use Steppers to guide users through a Wizard or multi-part form
- Number each step in sequential order
- Allow navigation back to completed steps for review or editing
- Use clear labels to describe each step's purpose

### Don't
- Use Steppers for simple single-step actions
- Overload with too many steps — consider grouping instead
- Lock users into only forward navigation unless justified
- Use vague or repetitive step titles
