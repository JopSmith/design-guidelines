# Image

## 1. Description

An Image component displays a single image within the interface and may include preview and transformation options such as zoom, rotate, or resize. It provides a structured and consistent way to present visual content while maintaining alignment with layout, spacing, and accessibility standards. The component ensures images are displayed clearly and responsively across different screen sizes.

## 2. Usage

### When to Use

Use an Image component when a single visual asset needs to be presented with optional interaction, such as previewing details or adjusting orientation. It is appropriate when the image supports the content or task and may require closer inspection, but does not require a full image browsing experience such as a gallery.

### Do
- Use the Image component when a single visual asset supports the content or task
- Provide preview options when users may need to inspect details
- Include transformation options such as zoom or rotate when context requires it
- Ensure images are responsive and scale appropriately across screen sizes
- Provide meaningful alternative text for accessibility
- Maintain consistent aspect ratios and spacing within the layout

### Don't
- Use large images that distract from the primary purpose of the page
- Force users to open a separate view unnecessarily
- Include transformation controls that are irrelevant to the use case
- Allow images to overflow, distort, or break layout structure
- Leave important images without descriptive text alternatives
- Mix inconsistent image sizes that create visual imbalance
