# Menu

## 1. Description

A Menu is a list of actions or navigation options presented in a structured overlay or panel. It typically appears in response to a trigger such as a button or icon and displays a set of related choices in a vertical arrangement. A Menu helps organise actions in a compact and accessible way, allowing users to quickly select an option without cluttering the main interface.

## 2. Usage

### When to Use

Use a Menu when you need to present a group of related actions or navigation links that are secondary to the primary content. It is particularly useful for contextual actions, overflow options, or account controls where space is limited and keeping the interface clean is important.

### Do
- Use a Menu to group related secondary actions or navigation options
- Keep menu items concise and clearly labelled
- Order items logically (e.g. alphabetically) or sometimes based on frequency or importance
- Use dividers to separate distinct groups of actions when necessary
- Ensure keyboard navigation and focus management are supported
- Close the Menu automatically after a selection is made when appropriate
- Anchor the menu to a clearly labelled trigger
- Use icons only when they improve recognition
- Use for overflow menus and context actions

### Don't
- Place primary or critical actions where they may be overlooked
- Use vague or ambiguous action names
- Arrange options in a random or inconsistent order
- Overload the Menu with too many unrelated items
- Rely solely on mouse interaction
- Leave the Menu open in a way that obstructs the interface unnecessarily
- Use vague triggers that don't describe the menu's contents
- Add the same icon to every item or put icons on both sides
- Replace form inputs that require a persistent selected value (use Select instead)

## 3. Composition

The Menu consists of the following accessories:

| Accessory | Required | Description |
|---|---|---|
| Icon | Optional | A leading or trailing icon used to add visual interest |
| Avatar | Optional | Allows a user avatar to appear |
| Badge | Optional | Allows a badge to display a count or notification |
| Checkbox | Optional | Allows menu items to show as selected |
| Divider | Optional | Adds an extra visual indicator to identify groupings |
| Group | Optional | Allows the list to be segmented by showing group subheadings |
| Header | Optional | Can be used to provide a filtering option |
| Subtitle | Optional | Appears below the title and used for secondary text |
