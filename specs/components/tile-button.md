# TileButton

## 1. Description

A TileButton component is a large clickable container with prominent visual treatment, designed to highlight important actions and shortcuts. It typically includes a central icon with a clear title and is styled to stand out within a layout. Unlike informational Tiles, which present content, a TileButton is action-focused and functions as a highly visible trigger that directs users to a feature, workflow, or key destination.

## 2. Usage

### When to Use

Use a TileButton for dashboard shortcuts, primary feature access, or workflow entry points that require greater visual prominence and generous touch-friendly interaction areas. It is particularly effective when key actions need to be easily discoverable and quickly accessible. Avoid using TileButtons for minor or secondary actions where a standard button would provide sufficient emphasis.

### Do
- Use TileButtons for high-priority actions and primary workflow entry points
- Keep labels clear, concise, and action-oriented
- Include a strong visual cue such as a clear icon to reinforce meaning
- Ensure generous touch targets and spacing between TileButtons
- Maintain consistent sizing and alignment within a group
- Use them sparingly to maintain visual hierarchy

### Don't
- Use TileButtons for low-priority or rarely used actions
- Use vague labels such as "Click here" or "More"
- Rely on text alone without visual support where recognition would help
- Place TileButtons too close together, increasing accidental taps
- Mix inconsistent sizes or layouts in the same set
- Overuse TileButtons, reducing their prominence and impact

## 3. Composition

The TileButton consists of the following accessories:

| Accessory | Required | Description |
|---|---|---|
| Icon | Optional | An optional centrally aligned icon displayed above the title to support recognition and reinforce the meaning of the destination |
| Subtitle | Optional | An optional short line of supporting text displayed beneath the title to provide additional context or clarification about the destination |
