# ButtonGroup

## 1. Description

A ButtonGroup groups multiple related buttons together to present a set of actions in a compact, unified layout. It visually communicates that the buttons are connected and belong to the same functional context.

## 2. Usage

### When to Use

Use a ButtonGroup to trigger closely related actions that operate on the same content or selection, such as text formatting controls like bold, italic, and underline. ButtonGroups are most effective when actions are equally weighted and can be applied independently or in combination. They are well suited for toolbars and editing interfaces, where quick access to grouped actions improves efficiency. ButtonGroups should not be used for switching views, navigating between sections, or applying filters, as those patterns are better served by other controls.

### Do
- Use a ButtonGroup only when two or more buttons are meant to be used together as a set of related actions within the same context
- Group actions that act on the same content or selection
- Use ButtonGroups for related, lightweight actions such as formatting
- Make active or toggled actions visually distinct
- Use icons or short labels that are easy to scan in a toolbar
- Keep spacing, size, and style consistent within the group

### Don't
- Use a ButtonGroup for a single action or for buttons that don't have a clear relationship
- Use ButtonGroups to switch views or navigate between sections
- Use ButtonGroups for filtering or mode selection
- Leave applied actions without clear visual feedback
- Use long, descriptive labels that reduce scannability
- Mix button styles or sizes within the same ButtonGroup
