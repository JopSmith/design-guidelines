# Tile

## 1. Description

A Tile component is a visual content block that combines an icon and label to present information in a structured and easily scannable format. It is designed to create organised interfaces where content can be grouped into clearly defined units, such as features, metrics, or key areas of a system. Tiles emphasise visual categorisation, helping users quickly identify and understand distinct pieces of information at a glance.

## 2. Usage

### When to Use

Use a Tile to build dashboards, feature overviews, or navigation layouts that benefit from strong visual grouping and clarity. They are well suited to presenting summaries, metrics, or feature highlights, and can also function as links to provide quick access to related areas. Avoid using Tiles for dense textual content or highly detailed data where a more compact layout would be more effective.

### Do
- Use Tiles on home screens, dashboards, or navigation hubs
- Provide clear and concise labels describing the destination
- Use centrally aligned labels and icons for consistency
- Use approved icons from the Mosaic icon library
- Keep Tile sets manageable and scannable such as 8 to 12 Tiles

### Don't
- Overload a page with too many Tiles, making navigation harder
- Use vague or missing labels
- Misalign icons or labels
- Insert arbitrary or mismatched icons
- Use 16 or more Tiles without additional navigation support

## 3. Composition

The Tile consists of the following accessories:

| Accessory | Required | Description |
|---|---|---|
| Icon | Optional | An optional centrally aligned icon displayed above the title to support recognition and reinforce the meaning of the destination |
| Subtitle | Optional | An optional short line of supporting text displayed beneath the title to provide additional context or clarification about the destination |
