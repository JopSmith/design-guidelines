# Drawer

## 1. Description

A Drawer component is a panel that slides into view from the side of the screen, typically overlaying or pushing the main content aside. It provides a contained space for navigation, secondary tasks, or supplementary information while maintaining the user's context within the current page. Drawers help manage complexity by presenting additional content without requiring a full page transition.

## 2. Usage

### When to Use

Use a Drawer when you need to display supporting content or actions without disrupting the primary workflow. It is well suited to editing details, viewing additional information, or navigating between related sections while keeping the main page visible and accessible in the background.

### Do
- Use a Drawer for secondary tasks that should not require a full page transition
- Keep the content focused and relevant to the current context
- Provide a clear title and a visible close action
- Maintain the user's sense of place by keeping the underlying page visible
- Use appropriate width and layout to support readability
- Ensure consistent behaviour across the product
- Use the **AI Aura** style exclusively when the content has been generated by AI, clearly signalling to users that the information or response is system-generated

### Don't
- Use a Drawer for complex, multi-step workflows that would be clearer on a dedicated page
- Overload the Drawer with unrelated information or actions
- Rely solely on clicking outside the Drawer to close it
- Obscure critical background content that the user may need to reference
- Make the Drawer so narrow or crowded that content becomes difficult to scan
- Change placement, animation, or interaction patterns without clear reason
- Use the AI Aura style for manually written, static, or non-AI-generated content

## 3. Composition

The Drawer consists of the following accessories:

| Accessory | Required | Description |
|---|---|---|
| Title (Mandatory) | Mandatory | Displays the name of the Drawer |
| Subtitle | Optional | Appears below the title and used for secondary text |
| Back button | Optional | Allows users to return to the previous view within the Drawer flow |
| Brand logo | Optional | Displays brand identity within the Drawer header when required |
| Actions | Optional | Allows placement of elements in the header for actions such as filtering, closing, etc. |
| Tabs | Optional | Enables navigation between grouped sections within the Drawer |
| Footer | Optional | Provides a persistent area for key actions at the bottom of the Drawer |
| DialogDrawer | Optional | Presents a layered interruption within the Drawer for confirmations, decisions, or required input |
