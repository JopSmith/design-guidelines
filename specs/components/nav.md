# Nav

## 1. Description

A Nav component is a layout element used to position and organise one or more links together, either horizontally or vertically, within another component. It provides consistent alignment, spacing, and structure for grouped navigation items, ensuring that related links are presented in a clear and cohesive way. A Nav supports predictable navigation patterns across the interface.

## 2. Usage

### When to Use

Use a Nav when you need to present a structured group of links within components such as tabbed interfaces, headers, side panels, or footers. It is particularly useful when consistent alignment and spacing are required to maintain clarity and visual order across different sections of the product.

### Do
- Use a Nav to group related navigation links within a clear structure
- Maintain consistent alignment and spacing across all Nav instances
- Use clear and concise link labels
- Indicate the active or current state clearly
- Ensure accessibility with proper semantic markup and keyboard support
- Adapt orientation appropriately for horizontal or vertical layouts

### Don't
- Mix unrelated links within the same Nav grouping
- Vary layout patterns without clear reason
- Use vague or ambiguous navigation text
- Leave users unsure of their current location
- Rely solely on visual styling to communicate navigation structure
- Force a layout that reduces readability or usability on different screen sizes
