# Chart

## 1. Description

A Chart is a data visualisation component used to represent numerical or categorical information in a visual format, such as bars, lines, or segments. Charts help users identify patterns, trends, and comparisons more quickly than reading raw data.

## 2. Usage

### When to Use

Use Charts when the goal is to help users understand relationships, changes over time, or differences between values at a glance. Charts are most effective when they answer a specific question or support a clear insight, and when the data is simple enough to be interpreted visually. They should complement, not replace, precise data, especially in cases where exact values are important.

### Do
- Make important data immediately visible within the chart so users can understand key insights at a glance
- Use multiple visual cues — such as labels, patterns, or icons — to explain and differentiate data clearly
- Select a chart type that clearly supports the data and the intended insight
- Clearly label axes, legends, and units so values are immediately understandable
- Focus each chart on a single, clear message or question
- Use consistent, honest scales and intervals that accurately reflect the data
- Provide context, captions, or annotations to explain why the data matters

### Don't
- Hide critical data behind interactions such as hover, clicks, or toggles that users may never discover
- Rely on colour alone to communicate meaning, as it can reduce clarity and accessibility for some users
- Use a chart type that makes relationships or comparisons harder to understand
- Make users guess what data points, scales, or categories represent
- Overload a chart with too many variables or competing insights
- Manipulate scales in ways that exaggerate or distort interpretation
- Present charts without guidance or an intended takeaway
