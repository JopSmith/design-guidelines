# Toolbar

## 1. Description

A Toolbar component is a horizontal container used to organise related actions and controls within a single structured layout. It groups buttons, inputs, filters, or tools into clearly defined start, centre, and end sections, helping to create consistent and predictable interfaces. Toolbars support efficient interaction by keeping commonly used controls visible and aligned.

## 2. Usage

### When to Use

Use a Toolbar to present application actions, editor tools, or interface controls that belong to the same context or workspace. It is particularly effective when users need quick access to multiple related actions without navigating away. Avoid using it to house unrelated controls or to overcrowd the interface with low-priority actions that reduce clarity.

### Do
- Group related actions logically within the Toolbar
- Use clear visual alignment with defined start, centre, and end sections
- Keep frequently used actions easily accessible
- Use consistent iconography and labelling styles
- Ensure sufficient spacing between controls for usability
- Adapt the Toolbar layout responsively for smaller screens

### Don't
- Mix unrelated actions in the same Toolbar
- Place items randomly without consistent structure
- Bury primary actions among low-priority controls
- Mix inconsistent button styles or icon treatments
- Cramp too many controls into a tight space
- Allow controls to overflow or become inaccessible on smaller devices
