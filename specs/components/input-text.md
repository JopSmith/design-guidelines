# InputText

## 1. Description

An InputText is a form control that allows users to enter and edit a single line of text. It is used to capture structured or unstructured information such as names, titles, identifiers, or short responses. It typically includes a label, optional helper text, validation messaging, and states such as focus, error, or disabled to guide interaction and ensure clarity.

## 2. Usage

### When to Use

Use an InputText when users need to provide concise information that can be expressed in a single line. It is suitable for short entries where formatting is not required and where clarity, validation, and ease of completion are important to the overall task.

### Do
- Use an InputText for short, single-line responses such as names or titles
- Provide a clear and descriptive label
- Include helpful validation and guidance where necessary
- Match the input type to the expected data such as email or number
- Ensure accessibility through proper labelling and keyboard support
- Keep the field width appropriate to the expected content
- Size the InputText width to reflect the expected length of the content, reinforcing clear field affordance
- Use the **AI Aura** style exclusively when the content has been generated by AI

### Don't
- Use an InputText for long-form content that requires multiple lines
- Rely on placeholder text as the only form of labelling
- Display errors without explaining how to resolve them
- Use a generic text field when a more specific input type is available
- Design interactions that are difficult to navigate without a mouse
- Make inputs excessively long or too short for their intended use
- Use uniform or excessively wide fields that misrepresent the amount of information expected
- Use the AI Aura style for manually written, static, or non-AI-generated content
