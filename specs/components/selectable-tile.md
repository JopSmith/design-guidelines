# SelectableTile

## 1. Description

A SelectableTile component is a large interactive choice card that allows users to select one or more options by tapping or clicking. It typically combines an icon or illustration, a title, an optional subtitle, and a clear selection control such as a checkbox within a single unified block. By presenting options as visually distinct cards, it provides richer context and makes complex or conceptual choices easier to understand at a glance.

## 2. Usage

### When to Use

Use a SelectableTile when options are visually distinct, require supporting context, or benefit from stronger emphasis than a standard radio button or checkbox. They are particularly effective in onboarding journeys, configuration flows, and plan or feature selection where clarity and engagement are important. SelectableTiles can support either single selection or multiple selection depending on the use case.

### Do
- Use SelectableTiles when users need to compare a small set of meaningful choices side by side such as Personal vs Business account
- Use clear short titles that are easy to scan
- Pair each tile with an icon or illustration to aid recognition
- Use the checkbox or radio style state to clearly show what is selected
- Keep tiles the same size within a group
- Use tiles for high-level mode, plan, or configuration choices

### Don't
- Use Tiles when a standard checkbox group or radio group would work just as well — this adds unnecessary visual weight
- Use long paragraphs of text inside each tile
- Rely only on colour to differentiate tiles
- Make the entire tile clickable but hide the actual selection state as this feels ambiguous
- Mix different tile heights or layouts in the same group
- Use tiles for granular field-level input such as Yes/No or toggles
