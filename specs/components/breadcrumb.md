# Breadcrumb

## 1. Description

Breadcrumbs are a navigational component that displays a hierarchical path showing a user's current location within an application. They help users understand how a page fits into the broader structure and provide quick access to higher-level sections. Breadcrumbs support wayfinding by reducing disorientation in complex or multi-level experiences, allowing users to move backward efficiently without relying on browser controls.

## 2. Usage

### When to Use

Use Breadcrumbs in experiences with clear hierarchy and multiple levels, such as dashboards, content libraries, or nested navigation structures. They are most effective when placed consistently near the top of the page and kept concise, reflecting the logical structure users expect rather than every possible navigation step. Breadcrumbs should complement primary navigation, helping users reorient themselves and move upward in the structure without replacing other navigation patterns.

### Do
- Use Breadcrumbs only when the navigation hierarchy is deep enough (3+ levels) to meaningfully support orientation and wayfinding
- Use Breadcrumbs when content follows a clear, hierarchical structure
- Place Breadcrumbs consistently near the top of the page
- Make previous levels in the Breadcrumb trail clickable
- Use short, clear, user-friendly labels for each level
- Clearly indicate the current page as the final, non-interactive item
- Treat Breadcrumbs as a secondary navigation aid

### Don't
- Add Breadcrumbs to shallow structures with one or two levels, where they add visual noise without providing real navigational value
- Use Breadcrumbs in flat or linear experiences where hierarchy doesn't exist
- Move them around or hide them in less visible areas of the layout
- Include items users can't navigate back to
- Use long, technical, or ambiguous labels in the trail
- Style the current page like a link or make it clickable
- Rely on Breadcrumbs as the primary or only navigation mechanism
