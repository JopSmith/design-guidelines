# Editor

## 1. Description

An Editor, or Rich Text Editor (RTE), is an input field that allows users to create and format content with styling options beyond plain text. It typically includes controls for formatting such as bold, italic, headings, lists, links, and sometimes media insertion. An Editor enables structured and visually enhanced content creation while remaining within a web or application interface.

## 2. Usage

### When to Use

Use an Editor when users need to produce formatted content such as descriptions, announcements, knowledge base articles, or messages where structure and emphasis improve clarity. It is appropriate when plain text would limit expression or readability, but should be avoided for simple inputs where formatting is unnecessary.

### Do
- Use an Editor when users need formatted content such as headings, lists, or links
- Provide only the formatting controls that are necessary for the context
- Ensure formatting options are clear and intuitive
- Maintain consistent formatting styles across the product
- Support accessibility and keyboard interaction
- Guide users with placeholder text or examples where appropriate
- Allow resizing to match expected content length
- Ensure storage supports rich content (HTML, media, links)

### Don't
- Use an Editor for short or simple inputs where plain text is sufficient
- Overwhelm users with excessive or rarely used formatting options
- Rely on hidden or unclear controls that reduce usability
- Allow uncontrolled styling that breaks visual consistency
- Design interactions that rely solely on mouse input
- Leave the Editor without context or instructions when formatting expectations exist
- Lock editor height too small for long content
- Accept formatted input without the ability to save/display it correctly
