# Repeater

## 1. Description

A Repeater component allows users to dynamically add, duplicate, reorder, or remove groups of related input fields within a form. It is designed for situations where the same type of structured data — such as multiple addresses, contacts, or line items — needs to be entered more than once.

Rather than displaying many identical input groups by default, the Repeater enables users to create only the number of entries they require, keeping the interface organised and focused.

## 2. Usage

### When to Use

Use a Repeater when users may need to provide an unknown or variable number of similar data entries. It is particularly useful in longer or more complex forms where flexibility is required, helping to reduce visual clutter while maintaining consistency across repeated sections.

### Do
- Use when users need to enter multiple sets of similar data such as email addresses, phone numbers, medications, or team members
- Label each repeated section clearly to indicate context or sequence
- Allow users to add, reorder, or delete instances easily
- Keep repeated items compact and visually consistent
- Provide contextual help or examples for complex repeated inputs

### Don't
- Use for unrelated inputs or when only one instance will ever be needed
- Leave repeated sections unlabelled, which causes confusion
- Force users to navigate away or reload the page to modify repeated content
- Overload each item with excessive fields or visual noise
- Hide validation or help text within collapsed sections
