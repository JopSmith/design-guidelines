# Pattern Transformation Prompt

## 1. Task
You are given two inputs:
1. A template file named `pattern-template.md`
2. A source file (attached)

Your task is to transform the source file into the format defined in `pattern-template.md`.

## 2. Instructions
- Follow the structure and formatting of `pattern-template.md` exactly.
- Extract and include *all* information from the source file.
- Do **not** add any new information or make assumptions.
- Do **not** simplify, summarise, or omit any content, including guidelines.
- Preserve the original meaning and level of detail.

## 3. Output Requirements
- Produce a complete file that conforms to the template.
- Ensure the output is properly formatted.
- Ensure the output does **not** use tables.
- Ensure the output is available as a downloadable Markdown file.
- Ensure the name of the downloadable file is the name of the pattern, e.g. empty-states.md.
